# Debloater 1.10.1

## Button layout fixes
- Welcome guide: Back, Skip, Next and Finish now sit above Android's navigation bar, including three-button and gesture navigation.
- Welcome guide: both footer actions share the available width, allowing longer translated labels to wrap inside their buttons.
- Clean up my phone: the action footer now reserves space for Android's navigation bar too.

## Installation
Download **Debloater-v1.10.1.apk**. Android 11 or later. This update keeps the same application ID and permanent signing certificate as 1.10.0, so it installs in place and retains app data and backups.

## Verification
The release workflow runs translation checks, unit tests, debug build, Android lint, the missing-signing-credentials check, signed release build and permanent certificate verification. Visual confirmation on a physical phone remains pending.
