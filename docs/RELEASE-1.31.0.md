# Debloater 1.31.0

- **Support screen once per update:** the screen asking for support now appears once after you install or update the app, instead of at every start. Tick **Don't show this screen again** to hide it for good.
- **Buy me a coffee buttons:** the Home screen has a coffee icon in the top bar and a **Buy me a coffee** button at the bottom, both opening buymeacoffee.com/j0p3s.
- Translated into all 11 supported languages.

**Security notice:** for security reasons, all earlier release builds were removed from the Releases page. Download APKs only from this repository's Releases page.

Android 11+, versionCode 36, permanent signing identity unchanged. Installs over 1.30.0 and keeps app data/backups. The new screens were not yet viewed on a device.
