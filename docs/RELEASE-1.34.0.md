# Debloater 1.34.0

- **Language fixes:** the Permissions screen and the App updates card, including its error messages, were still in English in most languages. They are now translated in all 11 supported languages. The Indonesian "Uninstall" label is translated too.
- **Settings:** a new **Support the developer** section at the top, with a **Buy me a coffee** button.
- Operation logs, saved backup data and shell commands stay in English by design, and package descriptions from the debloat lists stay in English.

**Security notice:** for security reasons, all earlier release builds were removed from the Releases page. 1.34.0 is the only available build; download APKs only from this repository's Releases page.

Android 11+, versionCode 38, permanent signing identity unchanged. Installs over your current version and keeps app data/backups. The translations are machine-assisted; corrections from native speakers are welcome. The new screens were not yet viewed on a device.
