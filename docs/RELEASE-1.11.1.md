# Debloater 1.11.1

- Settings → Permissions validates Shizuku, Usage Access, Accessibility and installation-granted permissions, with setup links and refresh on return.
- The floating Accessibility cache bar shows processed/total and remaining apps, including the current app. Skips count as processed, not successful clears.
- Counter text covers supported locales. New permission labels currently have English/Portuguese coverage; other locales display English for those labels.

Android 11+, versionCode 17, same permanent signing key. Device/OEM testing remains pending.
